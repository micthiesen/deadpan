Use case: ui-mockup.
Create a beautiful, exceptionally polished, high-resolution product design board for DEADPAN, a native macOS structural video editor built for timing, awkward pauses, repeats and attention. This is a Figma-quality visual target for a real Rust/egui implementation, not marketing art or a website. Flat straight-on pixels, precise type and layout, no computer/device mockup, no perspective. Wide 3:2 board, highest practical resolution. Large hero screen plus four carefully legible detail screens and an interaction strip. Give the hero most of the visual space; present the smaller views as coherent related artboards, not tiny unreadable decorative thumbnails.

Visual character: calm, exact, tactile, editorial. Deep warm charcoal surfaces (#17191D), subtly lighter panels (#202329), near-white text, muted cool gray secondary text with readable contrast. Desaturated lavender is the selected structural beat, a fine warm yellow playhead, restrained mint for saved/ready states. Native macOS titlebar proportions and understated red/yellow/green controls. Refined system sans typography, monospaced numbers and keycaps, compact deliberate spacing, thin separators, modest 5-8 px radii, no huge pill buttons, no gradients/neon/glass, no dramatic shadows, no generic analytics/dashboard cards. Picture has visual priority and the controls feel like a serious crafted creative tool.

Hero: label above artboard "01 / EDIT". A complete 1440-ish logical-pixel editing workspace. Thin titlebar with "DEADPAN", project "The interview", saved indicator, Undo, Redo and small Keys button. Narrow left source library with two small film thumbnails, file names and type/duration; a quiet bottom import action. Large central 16:9 viewer shows a believable cinematic interview: fictional person in a beige sweater, seated in a quiet warmly lit room, an understated deadpan expression. Source / Sequence context switch above picture, unambiguous Sequence selected. Caption and exact frame/time readout below. A slim right inspector shows selected "Pause", "Hold", duration "11 f", picture "Freeze", sound "Silence"; plain scope "This occurrence". Bottom structural beat strip has a thin ruler/playhead and three visually distinct editable beat cards: "Answer" Source, "Pause" Hold "11 f", "Again" Repeat "3 total plays". Show a Repeat as one compositional object with subtle internal play ticks and a small disclosure, not flattened duplicate clips. Selection lavender, ordinary beats charcoal, little color/type marks and brief thumbnails. Status bar "NORMAL", "SEQUENCE", "Frame 143", named scope, and elegant key hints. It must be immediately obvious which beat a command will edit.

Detail artboards: "02 / COMMAND": command overlay anchored near the bottom of the same workspace, input ":hold-duration 11f", completion rows with descriptions and right-aligned keycaps, clear selected row and scope "Pause · Hold · This occurrence"; Enter applies, Esc cancels. "03 / REPEAT": a tighter edit view showing an expanded structural Repeat with a breadcrumb "Sequence › Again › Play 2 of 3"; scope chips "This play" and "All plays", one selected play and a tiny occurrence-specific exception badge; inspector "Total plays 3", "Gap 120 ms". Bottom board strip titled "KEYBOARD / INTENT BEFORE ACTION" with five compact state chips connected by delicate arrows: "NORMAL" → "3r" (count + operator pending, no timeout) → "3riw" ("3 total plays of inner word") → "Repeat · 3 plays".
