## Method and identity

The baseline is `cf796605` plus the unchanged inherited general-Split working
files. All 1,395 qualification inputs match the final placement-history build.
A scratch copy additionally pins 5,279 workspace, configuration and fixture
files. Only copied `crates/deadpan-audio/src/stages.rs` changes. Removing its
diagnostics recovers the baseline bytes exactly; `query_limits`, cancellation
and deadline checks, actual charge arithmetic and both work caps stay intact.
The main checkout receives no diagnostic code.

Each request lazily owns a fixed 256-site table. `#[track_caller]` attributes
accepted returned charges to exact file/line/column and canonical or optional
category. Refused amounts remain separate. Canonical failed spends dump once;
a final near-limit summary also catches child queries that refuse their last
reduced allowance before returning work. The latter label alone does not imply
failure; the fixture result establishes that. This trace cannot attribute
partial visits inside a child query that fails before returning its charge.

The fixed table uses 12,288 diagnostic heap bytes, its header 208 bytes and each
site 48 bytes on this compiler/platform. This overhead is diagnostic only.
Neither instrumented timings nor these sizes establish product performance or
residency qualification.

and opt-level 2 with debug assertions. The sole copied-target build passes in
59.24 seconds. The executed stage binary is copied from Cargo's JSON artifact

`08a28c0e3e89f963176157e5e01bcf1f3db2c5fcfb897a3ec103cc343230354f`.
