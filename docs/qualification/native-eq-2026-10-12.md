# Native EQ qualification, 2026-10-12

Deadpan now authors static three-band EQ and optional low/high cuts through
`:eq`, an inspector action and complete typed recipes. The captured unsaved
editor shares Gain's immutable proposal, Before/Draft audition, Apply and Cancel
lifecycle. A committed edit preserves both clocks and every other treatment;
one Undo restores the complete prior recipe. Typed whole-beat recipes support
dot and macros; one Repeat play uses occurrence isolation.

This implements native authoring for the previously qualified
[shared EQ processor](shared-eq-2026-10-12.md). DP-09 and DP-16 remain partial:
independently timed automation, arbitrary sends/incoming tails, broader binding
qualification and persistent filtered caching remain agent work.

## Contract and review

The three bands require exact values within −24 to +24 dB. Optional cuts accept
whole Hz from 80 through 20000, with the recipe's minimum 80 Hz passband. Typed
recipes require all three unit-bearing gains; omitted cuts are off. Duplicate,
unknown, incomplete, nonfinite and out-of-range input refuses without writes.
`:eq off` removes only EQ. Existing authored stage order is preserved.

The five fields buffer text until Set EQ validates them together. Apply cannot
save unfinished or invalid fields, and a failed Set retains the preceding valid
draft. Reset fields restores that recipe; opening without EQ does not author a
unity stage. Tab reveals the focused field or button at 960×640. Enter inside
a text field cannot apply; Escape discards the draft. Whole-beat scope is shown
explicitly, including when an Edit range is selected.

Single-agent review covered capture/revision checks, semantic recording, stage
preservation, proposal readiness, field focus and all changed code. No second
agent was used. Review removed the unused Gain waveform request from EQ entry.
Initial image review found Gain-labelled footer and owner rows; final captures
show EQ in both. Unsaved-close reporting also names EQ. Generic treatment-save
messages no longer call every audio recipe a gain change.
