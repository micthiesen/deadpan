# Native intrinsic-preflight policy admission

Intrinsic preparation now constructs the actual Signal, Tape and after-Preserve
Tape policies through native admission. Each input query retains its content
inventory, final range allocation and retained admission guards through content checks,
ordinary graph construction/debit and recursive preflight. Output policy owners
remain live through their content checks. Query destruction releases the real
request-ledger leases before the enclosing use scope exits.

The private helper dispatches by the actual SignalInput tag to the existing
admitted factories. Its temporary mutable StageAudio borrow ends before returning
the owner, so nested preflight can use the same controller and request issuer.
The existing input-before-output order, frame checks, cursor ranges, policy
before graph priority, recursive depth checks, memo keys and canonical work stay
intact. Forwarded query work is not manually charged again.

Mix voice queries remain ordinary controls. Graph queries, PCM and dependency
construction, immutable Plan storage and whole preparation are outside this
ownership change. This discard-only seam adds no final-mask handoff or replacement
copy and does not change the existing routed Tape custody protocol. No requirement,
coverage score or product Gate status changes. General sound-bearing Split
remains disabled in shipping Scope.
