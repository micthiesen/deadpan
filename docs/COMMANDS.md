# Command and key reference

Generated from the action registry in
[`registry/entries.rs`](../crates/deadpan-app/src/navigation/registry/entries.rs)
by `cargo test -p deadpan-app --bin deadpan-app commands_reference`; set
`DEADPAN_UPDATE_COMMANDS_MD=1` to rewrite it. Do not edit it by hand.
Keys are the shipped logical defaults; a personal
[keymap](KEYMAP.md) changes configurable paths, and the app's Keys sheet
(`?`) always shows the live ones. Fixed mode keys are not configurable;
tests prove each mode router acts on exactly them. Native shortcuts
(menus, ⌘ chords, panel controls) are described, not router-verified.
Headless status links to [PARITY](PARITY.md).
