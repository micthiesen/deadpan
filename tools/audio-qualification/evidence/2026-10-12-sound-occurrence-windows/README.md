# Sound occurrence window evidence

The sampled route retains a visible interval and rounding anchor for every
placement while keeping the complete original preparation input. Old clipped
samples cannot return after a move or later expansion. The existing production
identity-anchor method uses this path with full windows.

The dense plan oracle covers fractional clocks, changing anchors, disjoint and
sampleless windows, shuffled reads, query budgets and invalid input. A real
decoded-audio test selects output from nested Preserve stages, checks complete
hidden input and refuses a revoked source even for clipped silence.

`commands.json` and compressed logs retain failed and successful attempts with
source-state and executed-binary hashes. `identity.json` and
`implementation.patch` bind the final source. `checks.py`/`run.py` reproduce the
ordered validation with the qualified FFmpeg prefix. Run
`python3 check-evidence.py --source` here to check retained evidence and source,
or omit `--source` after later source changes.

The primary agent implemented and self-reviewed this work alone. Partial
attached-sound copies remain guarded pending capture and gate integration.
There is no new live GUI, physical device, listening or release qualification.
