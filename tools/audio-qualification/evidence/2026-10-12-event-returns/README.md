# Independent sound-return evidence

Run `python3 check-evidence.py` here to validate retained commands, source patch,
actual export, replay reports and file hashes. Add `--source` only when the
checkout still has this implementation. Historical evidence stays verifiable
without that option.

`identity.json` identifies source and executed release binaries; command receipts
retain their start-time HEAD, working diff and new-file hashes. The implementation
patch is relative to the declared base commit. Failed fixture, parser and
intentional generated-reference runs are retained alongside passing validation.

The actual movie and authoritative project are retained. PNGs are offscreen Metal
captures, inspected by the primary agent against the design boards. No live app,
audio device or physical listening was used. Tests and builds ran serially; no
source edits occurred during validation. The primary agent worked alone.
