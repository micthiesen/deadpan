# Scoped Follow creep map

## Preferred first scope

Support Keep-center Follow creep for a whole owner inside a concrete This play selection, with one enclosing Repeat explicitly resolved to a stable Play and an ordinary Source, Hold, or Sequence as the selected owner. Keep Default branch, Visual selection, ambiguous/mismatched presentation, and mixed or nested Repeat/Retime occurrence scopes refused in this first increment. This is the smallest authority surface already represented by SemanticScopedContext and satisfies the spec’s This play promise without changing shared definitions.

Default/shared-body edits are separate: the regular unscoped zoom path edits the authored definition and applies to every play. Do not make a Default ScopedNodeTarget stand in for a visible occurrence. Spec §5.2 states default edits affect every iteration, while one occurrence requires explicit InstancePath authority; §8.2 calls for creep over a repeated group. Section 7.5 says one-play framing uses explicit invocation occurrence authority and must never fall back to changing the shared definition. Avoid conflating a default shared edit with a selected-play override.

## Clock and copy-on-write behavior

ScopedNodeTarget/RepeatEditBranch live in crates/deadpan-core/src/scoped_edit.rs:29-110. RepeatEditBranch::Play names a stable IterationId; Default is the shared authored body. Target repeats are outermost first. PreparedScopedEdit at :298-345 records identity mappings and maps both target and a concrete InstancePath through isolation. Command execution applies the scoped edit to isolated copies, preserving unrelated plays; scoped SetFraming is the typed edit at :135-185.

A selected owner cloned out of its Repeat branch has the same authored duration unless the selected structure itself was changed. FramingClock::OwnerOutput in crates/deadpan-core/src/framing.rs:136-169 is therefore the right clock for creep over that selected owner; it follows the clone’s own output coordinate and duration. RetainedOutput is for a previously captured window surviving structural changes, not the default clock for a fresh whole-owner creep. The target ID remains the same, and RenderPlan resolves it from each emitted Source picture’s actual SourcePoint after Repeat/Retime traversal (plan.rs:1293-1360, 1638-1715). Thus transition scale belongs to selected owner time while target center stays live on mapped provider time.

If the selected owner is below a Retime, its own local/output time is the natural clock; if the selected owner is the Retime, its output duration is the clock and the target still resolves from mapped child SourcePoint. Do not use the play’s project-frame cursor as transition progress. Defer selected nodes spanning nested Repeat and Retime layers until tests establish the exact cloned owner extent and all mapped clocks.

## Required refusals and risks

Retain refusal for a Visual selection including full-length range; no scoped context or selected play; Default branch; presentation/target mismatch; any enclosing Repeat not explicitly chosen; dormant/default-only target without a concrete play; Original mode; empty owner; clipped/missing target rules; and a second creep on an already animated Follow under the existing PATH_REFUSAL policy unless the user explicitly replaces the path with a target. One Undo must restore the exact branch; redo must not affect other stable iteration IDs.

First fixture: one three-play Repeat over a moving-target Source/Sequence. Give the shared template a fixed Follow; choose play 2 explicitly; creep Keep and verify owner-local endpoint scales plus target centers at mapped SourcePoints over every picture of that play. Confirm plays 1 and 3 remain fixed Follow, one undo/redo isolates/restores only play 2, and a recorded macro replayed on play 1 resolves invocation-time Keep to that play’s branch. Add history-free refusal checks for Default and mismatched occurrence. This demonstrates explicit selected-play framing; it does not qualify nested mixed scopes or `This play` when a Retime intervenes.
